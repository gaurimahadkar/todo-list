# To-Do List Application

## About the Project
The To-Do List Application is a simple and user-friendly project that helps users manage their daily tasks efficiently. Users can add tasks, view their tasks, update them, and delete completed or unnecessary tasks.

## Features
- Add new tasks
- View all tasks
- Edit or update tasks
- Delete tasks
- Mark tasks as completed
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
```text
todo-list/
├── todo-list/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── README.md
```

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Start adding and managing your daily tasks.

## Purpose
This project was developed to practice frontend development and learn how to build an interactive web application using HTML, CSS, and JavaScript.
